# 🚀 TDD - Práticas de Testes em Java (JUnit 5 & Maven)

Este repositório contém a implementação de exercícios práticos desenvolvidos utilizando a técnica de **TDD (Test-Driven Development)** em Java, utilizando o **Maven** para gerenciamento de dependências/build e **JUnit 5** para a suíte de testes unitários.

---

## 🛠️ Procedimentos de Build e Execução de Testes

Certifique-se de ter o **Java JDK 21+** e o **Maven** instalados e configurados no seu ambiente.

### 1. Clonar o repositório e navegar até a pasta do projeto
Abra o seu terminal na pasta do projeto (`exc-tdd`):
```bash
cd exc-tdd
```

### 2. Limpar e Compilar o Projeto 

```bash
mvn clean compile
```

### 3. Executar a Suíte de Testes Unitários 

```bash
mvn test
```

### 4. Executar o Build Completo

```bash
mvn clean package
```
